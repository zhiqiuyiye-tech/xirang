# Control Panel 1.0.16

Release validation date: 2026-10-14.

## Changes

- Align virtual volume deletion and NFS reclaim with `NFS创建流程.md`:
  remove target exports and refresh exportfs, ordinarily unmount host paths,
  release exact-device namespace copies, verify stable LV identity and
  Open Count=0, remove the LV, then clean its fstab entries.
- Remove Kubernetes Pod/PVC scanning, maintenance enablement, per-task
  maintenance checkbox and workload allowlist prerequisites from these two
  deletion flows. Keep resize's existing workload and inspection checks.
- Use process mountinfo and ordinary namespace operations on Linux 5.10,
  without requiring Linux 6.12 namespace enumeration ioctls. Match major/minor
  device IDs exactly; inspect only relevant holder roots and preserve pinned
  PID/namespace/root/mount-ID verification, protected paths and topology checks.
- Retain stop-on-error/busy behavior, release verification and timeout quarantine;
  never force/lazy unmount, kill business processes, or delete Pods/PVCs.
- Simplify the delete/reclaim UI to direct irreversible confirmation with clear
  warnings: operators must stop business use and confirm data is disposable;
  the backend no longer checks Kubernetes references. Prevent duplicate submits.
- Keep old maintenance/allowlist settings accepted for configuration compatibility;
  they no longer enable, authorize or block the handbook deletion flow.

## Validation and operational limitations

- Full Go tests, `go vet ./...`, and `go build ./...`.
- 62 Python parser/physical-protection tests and Ruff checks.
- 60 frontend/deployment tests, including UI/Helm version consistency.
- JavaScript syntax, whitespace and Helm chart validation.

Tests use fixtures and temporary databases. No real Worker volume was deleted.
Isolated Linux acceptance of namespace/root handling, propagation, busy mounts
and helper termination remains required; Windows mocks do not prove production
behavior. Open Count=0 is not proof that an idle PVC's data is disposable.

UI, Helm chart version and appVersion are 1.0.16. The independent browser-crypto
build tooling remains at 0.1.0. This source release does not publish an image or
OCI chart, or deploy to production. Development database and local plan files
are excluded from the release commit.
