# Control Panel 1.0.15

Release validation date: 2026-10-14.

## Changes

- Fix virtual volume deletion failure on nodes where target mounts or parent mounts
  have shared propagation:
  - Fix mountinfo parsing for synthetic `nsfs` root records such as `net:[<id>]`.
  - Fix incorrect propagation failure on shared leaf mounts under private parents;
    leaf removal events are governed by the parent mount, not the leaf's own shared tag.
  - Proactively scan, authorize, and clean up residual container mounts (e.g. Promtail)
    after host unmount and before `lvremove`, verifying `Open Count=0` before volume removal.
  - Add controlled shared-host maintenance mode for Linux 5.10 nodes where kernel
    enumeration ioctls are unavailable; requires explicit server configuration and
    per-task confirmation checkbox.
  - Document manual Promtail namespace unmount procedure in `control_panel/docs/NFS创建流程.md`.

- Frontend test suite (63 tests pass).
