| 错误码 | 错误描述 | 出现原因 | 解决方法 |
| --- | --- | --- | --- |
| auth.gateway.450 | 请求未提供认证信息Hybrid-Authorization,认证失败. | 未添加Hybrid-Authorization请求头信息 | 依据规定格式以及对应数据添加认证信息 |
| auth.gateway.451 | 请求未提供认证信息ctyun-hybrid-request-id,认证失败. |未添加ctyun-hybrid-request-id请求头信息 | 依据规定格式以及对应数据添加认证信息 |
| auth.gateway.452 | 请求未提供认证信息hybrid-date,认证失败. |未添加ctyun-hybrid-request-id请求头信息 | 依据规定格式以及对应数据添加认证信息 |
| auth.gateway.453 | 请求头Hybrid-Authorization、ctyun-hybrid-request-id和hybrid-date值不能为空. | 上述三个头信息中存在空值 |依据规定格式以及对应数据添加认证信息|
