# 天翼混合云资源查询 API 使用文档

本文档基于天翼混合云 OpenAPI 与官方 Python SDK,描述两个已验证可用的资源查询功能:查询物理机库存、获取单资源池的总量和剩余量。

- 混合云版本:v2.2.3 及以上(支持 OpenAPI 3.0)
- 适用资源池底座:3.0 与 4.0
- SDK 位置:`api/ctyun-hybrid-python-sdk/`
- 签名方式:混合云签名(`signer="hybrid"`)

---

## 1. 通用前置条件

两个接口共用以下配置,需先完成才能成功调用。

### 1.1 凭证获取

通过云管界面「用户信息」获取 `ctyun-eop-ak` / `ctyun-eop-sk`。

> 注意:**超管无法创建 AK/SK**,必须使用「租户」类用户创建。AK/SK 与所在网关环境绑定,跨环境不通用。

### 1.2 网关访问地址

混合云管 API 统一通过网关访问,默认地址:

```
http://ct-global.ctapi.ctyun.local:12320
```

需在本机 hosts 文件中配置域名映射(管理员权限编辑 `C:\Windows\System32\drivers\etc\hosts`):

```
<云管ip>  ct-global.ctapi.ctyun.local
```

其中 `<云管ip>` 由负责环境的运维人员提供。

### 1.3 签名认证

接口采用混合云 HMAC 签名,SDK 内部自动完成签名构造,无需手动计算。关键点:

- 客户端构造时必须指定 `signer="hybrid"`
- SDK 自动注入并签名的请求头:`ctyun-hybrid-request-id`、`hybrid-date`、`Hybrid-Authorization`
- 业务侧需补充的请求头:`userId`、`Accept-Language`

签名算法与错误码详见 [`docs/网关签名说明.md`](网关签名说明.md) 与 [`docs/网关EOP签名说明.md`](网关EOP签名说明.md)。

### 1.4 限流

单用户单接口并发 **1 个/秒**,不同用户并发互不影响。

### 1.5 通用请求头

| 请求头 | 必选 | 说明 | 示例 |
| --- | --- | --- | --- |
| `userId` | 是 | 用户 ID(云管界面获取) | `257230714868618` |
| `Accept-Language` | 否 | 语言 | `zh-CN` |
| `x-ctyun-user-id` | 否 | 用户 ID(可选,与 userId 二选一) | `257230714868618` |

> `ctyun-hybrid-request-id`、`hybrid-date`、`Hybrid-Authorization` 由 SDK 自动生成与签名,业务侧无需设置。

### 1.6 通用响应结构

所有接口统一返回如下结构:

```json
{
  "description": "成功",
  "errorCode": "SUCCESS",
  "message": "success",
  "returnObj": { ... },
  "statusCode": 800,
  "traceID": "xxx"
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `statusCode` | int | 状态码。`800`=成功,`900`=失败 |
| `errorCode` | string | 错误码。成功为 `SUCCESS` |
| `message` | string | 错误说明 |
| `description` | string | 描述 |
| `returnObj` | object | 业务返回对象,各接口不同 |
| `traceID` | string | 链路追踪 ID |

### 1.7 常见错误排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 响应 body 为空、SDK 误报 `statusCode=800/success` | hosts 未配置或被代理拦截(网关不可达) | 配置 hosts 映射,关闭/绕过系统代理 |
| `CTAPI_AUTH_1007` / `CTAPI_AUTH_MissConsumer` / `invalid appID` | AK 未在网关注册或失效 | 用租户类用户重新创建有效 AK/SK |
| `auth.gateway.460` 签名不一致 | 签名计算异常 | 核对 AK/SK、SDK 版本,见 [网关签名说明.md](网关签名说明.md) |
| `Compute.RegionNotFound` | `regionID` 在当前环境不存在 | 向运维确认真实资源池 ID |
| `Compute.AvailableZoneNotFound` | `azName` 在当前资源池不存在 | 传真实可用区名,或置 `None` 不传 |
| `auth.gateway.454` 签名时间戳超 5 分钟 | 客户端时间偏差过大 | 校准本机系统时间 |

## 2. 查询物理机库存

查询指定资源池下物理机(裸金属)的可售库存。

- **接口路径**:`GET /v4/ebm/device-stock-list`
- **SDK 客户端**:`EbmClient`(`services.ebm.client`)
- **SDK 方法**:`client.query_devices_stock(request)`
- **示例脚本**:`api/query_device_stock.py`

### 2.1 请求参数

| 参数名 | 位置 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- | --- |
| `regionID` | query | 是 | string | 区域/资源池 ID |
| `deviceType` | query | 否 | string | 设备类型,如 `physical.t1.large`;留空返回全部 |
| `azName` | query | 否 | string | 可用区(**4.0 资源池必填**);3.0 资源池可不传 |
| `count` | query | 否 | string | 所需库存数。**公有云字段,混合云暂不支持,忽略** |

> 3.0 资源池如不确定可用区名,可将 `az_name` 置 `None`,SDK 不会发送该参数,由网关自行判定。

### 2.2 请求示例(Python SDK)

```python
# coding=utf-8
import json, sys, os
sys.path.append(os.path.join(os.path.dirname(__file__), "ctyun-hybrid-python-sdk"))

from ctyun_hybrid_sdk.services.ebm.querydevicesstock.request import (
    QueryDevicesStockRequestParam, QueryDevicesStockRequest)
from ctyun_hybrid_sdk.services.ebm.client import EbmClient
from ctyun_hybrid_sdk.core.credential import Credential
from ctyun_hybrid_sdk.core.config import Config
from ctyun_hybrid_sdk.core.const import SCHEME_HTTP

# 1. 凭证
credential = Credential(access_key="<AK>", secret_key="<SK>")

# 2. 网关配置(路径已封装在 Request 内,无需指定)
config = Config(endpoint="ct-global.ctapi.ctyun.local:12320",
                scheme=SCHEME_HTTP, timeout=10)

# 3. 客户端(混合云签名)
client = EbmClient(credential, config, signer="hybrid")

# 4. 请求参数
request_param = QueryDevicesStockRequestParam(
    region_id="26060791011_jx_sr",
    device_type="",    # 留空返回全部设备类型
    az_name=None,      # 3.0 资源池可不传;4.0 必填真实可用区名
)

# 5. 构造请求并补充业务头
request = QueryDevicesStockRequest(request_param)
request.header["userId"] = "257230714868618"
request.header["Accept-Language"] = "zh-CN"

# 6. 发送
resp = client.query_devices_stock(request)
print("statusCode:", getattr(resp, "statusCode", None))
print("returnObj:", json.dumps(getattr(resp, "returnObj", None),
                              indent=4, ensure_ascii=False))
```

### 2.3 响应示例

```json
{
  "description": "成功",
  "errorCode": "SUCCESS",
  "message": "success",
  "statusCode": 800,
  "returnObj": {
    "totalCount": 1,
    "results": [
      {
        "az": "",
        "available": 2,
        "success": true,
        "deviceType": "physical.pak2.1large1",
        "device_type": "physical.pak2.1large1"
      }
    ]
  }
}
```

### 2.4 returnObj 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `totalCount` | string | 总记录数 |
| `results` | array | 库存明细列表 |
| `results[].az` | string | 可用区 |
| `results[].available` | string | 可用物理机数量 |
| `results[].success` | string | 是否库存充足 |
| `results[].deviceType` | string | 套餐类型 |

## 3. 获取单资源池的总量和剩余量

查询单个资源池的容量概览:VCPU、内存、块存储、对象存储、文件存储、IP 的总量与已用量,以及宿主机/裸金属/虚机数量等。

- **接口路径**:`GET /v4/region/get-total-remain-metric`
- **SDK 客户端**:`CommonClient`(`services.common.client`)
- **SDK 方法**:`client.get_region_total_remain_metric(request)`
- **示例脚本**:`api/query_region_total_remain.py`
- **接口状态**:`deprecated`(仍可用,混合云按 upms 接口开发,对所有用户开放查询)

### 3.1 请求参数

| 参数名 | 位置 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- | --- |
| `regionID` | query | 是 | string | 资源池 ID |
| `poolType` | query | 否 | string | 查询全部资源池类型;**暂只支持 `maz`(4.0 的 maz),其他忽略;该参数暂不支持,可不传** |

### 3.2 请求示例(Python SDK)

```python
# coding=utf-8
import json, sys, os
sys.path.append(os.path.join(os.path.dirname(__file__), "ctyun-hybrid-python-sdk"))

from ctyun_hybrid_sdk.services.common.getregiontotalremainmetric.request import (
    GetRegionTotalRemainMetricRequest, GetRegionTotalRemainMetricRequestParam)
from ctyun_hybrid_sdk.services.common.client import CommonClient
from ctyun_hybrid_sdk.core.credential import Credential
from ctyun_hybrid_sdk.core.config import Config
from ctyun_hybrid_sdk.core.const import SCHEME_HTTP

# 1. 凭证
credential = Credential(access_key="<AK>", secret_key="<SK>")

# 2. 网关配置
config = Config(endpoint="ct-global.ctapi.ctyun.local:12320",
                scheme=SCHEME_HTTP, timeout=10)

# 3. 客户端(混合云签名)
client = CommonClient(credential, config, signer="hybrid")

# 4. 请求参数
request_param = GetRegionTotalRemainMetricRequestParam(
    region_id="26060791011_jx_sr",
    pool_type=None,    # 暂不支持,置 None 不发送
)

# 5. 构造请求并补充业务头
request = GetRegionTotalRemainMetricRequest(request_param)
request.header["userId"] = "257230714868618"
request.header["Accept-Language"] = "zh-CN"

# 6. 发送
resp = client.get_region_total_remain_metric(request)
print("statusCode:", getattr(resp, "statusCode", None))
print("returnObj:", json.dumps(getattr(resp, "returnObj", None),
                              indent=4, ensure_ascii=False))
```

### 3.4 returnObj 字段说明

#### returnObj 顶层

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `poolName` | string | 资源池名称 |
| `capacity` | object | 容量信息(见下表) |
| `compute` | object | 计算节点概览(`computeCount` 节点数、`arch` 架构列表) |
| `storage` | object | 存储节点概览(`storageCount` 节点数) |

#### capacity 关键字段

| 字段 | 说明 | 配套单位字段 |
| --- | --- | --- |
| `totalCpu` / `cpuUse` | VCPU 总量 / 已分配量 | — |
| `totalMemory` / `memUse` | 内存总量 / 已分配量 | `memUnits` / `memUseUnits` |
| `totalDisk` / `allocatedDisk` | 块存储总量 / 分配量 | `diskUnits` / `diskAllocatedUnits` |
| `totalOss` / `ossUse` | 对象存储总量 / 已用量 | `ossUnits` / `ossUseUnits` |
| `totalSfs` / `sfsUse` | 文件存储总量 / 已分配量 | `sfsUnits` / `sfsUseUnits` |
| `ipTotal` / `ipAllocated` / `ipRemainingTotal` | IP 总量 / 已分配 / 剩余 | — |
| `totalHost` / `totalBms` / `totalEcs` / `totalPhysicalCore` | 宿主机 / 裸金属 / 虚机 / 物理核 总量 | — |

> 完整字段(含块存储/对象存储/文件存储的 HDD/SSD 服务器台数与可售/已分配明细)参见 [`docs/获取单资源池的总量和剩余量.md`](获取单资源池的总量和剩余量.md)。

## 4. 附:Windows 运行注意

Windows 控制台默认 GBK 编码,`print` 中文会乱码。脚本中需在导入前重置标准输出编码:

```python
import sys
if sys.platform == "win32":
    try:
        sys.stdout.reconfigure(encoding="utf-8")
        sys.stderr.reconfigure(encoding="utf-8")
    except Exception:
        pass
```

`query_region_total_remain.py` 已内置该处理;`query_device_stock.py` 输出以英文为主,如需中文展示可同样加上。

## 5. 运行

```bash
# 查询物理机库存
python api/query_device_stock.py

# 获取单资源池总量和剩余量
python api/query_region_total_remain.py
```

成功运行后,两个脚本均会打印 `statusCode`、`errorCode`、`message`、`description`、`returnObj`;资源池容量脚本还会额外打印「关键指标摘要」。
