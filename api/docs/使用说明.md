# 使用说明

OpenAPI 接口是混合云目前针对  3.0和4.0 池子纳管后，对第三方使用的接口。

## 接口使用前提条件：
- 确定项目建设的支持资源池底座是3.0和4.0
- 确定项目使用的混合云云管版本（最低v2.2.3及以上版本）支持 openapi3.0 
- 根据文档接口评估功能满足情况，不满足需求的功能，通过项目提需求，排期提供。

## 混合云管api访问方式：
   1. 配置host`<云管ip>  ct-global.ctapi.ctyun.local`
   2. 使用 http://ct-global.ctapi.ctyun.local:12320 访问，需要注意 如果需要平台接入 单独联系一下 混合云支持

## 接口使用必读
- 调用接口入参和返回主要需要兼容多余字段增加
比如：接口 A 在第一期发布时入参时a,b两个参数，返回有 c,d字段， 第二期兼容格式迭代，入参为a,b,c(非必填)，返回为 c,d,e字段。
- 调用接口需要签名认证，具体查看[网关签名说明](https://s.apifox.cn/5de76005-54b8-4f68-82de-fb575aa5b2fe/3877566m0.md)
- 接口限流单用户单接口并发1个/s， 不同用户并发之间互不影响

## 使用步骤
- 与负责环境的运维工作人员确认调用网关的具体地址路径。
- 获取签名认证所需的ak/sk信息。
- 获取用户ak/sk：通过云管界面用户信息获取ctyun-eop-ak,ctyun-eop-sk ，注意超管无法创建ak/sk，请使用“租户”类用户创建。
- 依据[网关签名说明](https://s.apifox.cn/5de76005-54b8-4f68-82de-fb575aa5b2fe/3877566m0.md)或混合云签名算法demo构造网关签名认证所需的请求头信息。
- 根据上述获取的信息调用接口，示例如下：

| 调用接口所需信息 |  描述| 范例值 |
| --- | --- | --- |
| 调用接口及入参 | 通过部署的网关地址端口调用接口 | http://ip:port/v4/vpc/get-nat-gateway-attribute?regionID=nm8&natGatewayID=natgw-u4z12jh88f |
| 请求头参数 | 新增请求头hybrid-date | 20230403T154057Z |
| 请求头参数| 新增请求头ctyun-hybrid-request-id | 0y13p5g41hwr |
| 请求头参数| 新增请求头Hybrid-Authorization | 470bbc5b-10f5-4d7f-bae6-2275046380b3 Header=hybrid-date;ctyun-hybrid-request-id Signature=ejXRxfQRbpKRzDKd24QV55Bgih4j4iQJVVZdfBa6xLY= |
- 若请求返回信息为[网关常见问题说明](https://s.apifox.cn/5de76005-54b8-4f68-82de-fb575aa5b2fe/3877567m0.md)中签名插件常见问题，则网关签名认证未能通过，请返回上一步骤确认构造签名认证所需请求头信息中存在的问题。
- 若返回信息为接口文档中对应返回示例，则接口调用成功。
> 调用成功示例:
{
	"description":"成功",
	"errorCode":"SUCCESS",
	"message":"success",
	"returnObj":{},
	"statusCode":800
}
